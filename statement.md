# Problem Statement

## Problem
Managing food orders manually is time consuming and may lead to mistakes while recording customer details, calculating order amount, applying discounts and generating a final bill. My program helps tackle this by automating this process. It saves customer info, lets them view the menu and order items. It then calculates the final order amount, applies discount based on it and generates an order summary.  

## Scope 
A single user, command line program. Data is only saved while the program is running.

## Target Users
Cafe/Restaurant owners who want to add a self-service option at their cafe. 

## Features
1. Saves customer name and phone number
2. Lets customer order food items
3. Calculates the total order amount and applies discount based on it
4. Generates an order summary
